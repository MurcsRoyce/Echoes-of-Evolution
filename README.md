# Echoes of Evolution

A table top card game project.

## Overview
This repository contains the design and development of Echoes of Evolution, a strategic table top card game.

## Mobile App (Phone Companion)
This repository now includes a React Native + Expo mobile app in `mobile-app/` to support live tabletop sessions.

### Features in the first build
- Two-player health tracking with quick +/- controls
- Turn and evolution energy tracking
- Random world event/encounter generator
- Match notes panel
- One-tap match reset

### Run on your phone
1. Install **Expo Go** on your Android or iOS device.
2. From this repository run:
   ```bash
   cd mobile-app
   npm install
   npm start
   ```
3. Scan the QR code from the terminal with Expo Go.
